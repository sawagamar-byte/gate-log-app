Cameras

Each camera connects by calling its local IP address directly from this page and reading the plate out of its response. This only works if the camera exposes an HTTP JSON endpoint on your network, allows cross-origin requests, and this page is opened over plain HTTP (not HTTPS) on the same network — browser security blocks it otherwise. If a camera won't connect, you can still log its plates manually in "New entry".
